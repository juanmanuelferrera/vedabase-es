# vedabase-es

Traducciones al español de libros de Śrīla Prabhupāda, hechas desde el texto último (revisado) de Vedabase, junto con una página de biblioteca para consultarlas.

**Material de consulta, no es primera edición.** No sirve como fuente para `vedabase-original`, que solo admite la edición original; usarlo allí metería texto revisado en el corpus.

## Estructura

- `books/` — un directorio por libro (22), con sus capítulos en español.
- `en/library/` — copia de consulta en inglés.
- `index.html` — página «Vedabase en Español — Biblioteca de Śrīla Prabhupāda», estática y sin dependencias de compilación; se abre directamente en el navegador.
- `QUE-ES-ESTO.md` — nota sobre qué es este repo y su estado.

## Estado

Se conserva como consulta. Desde octubre de 2026 no se versiona la salida de máquina.
